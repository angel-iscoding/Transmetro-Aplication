# Transmetro-Aplication

Responsive web application and PWA for real-time bus tracking, developed with Next.js and TypeScript. It offers interactive map visualization, browser notifications, and route search optimized for mobile devices.

## Technology Stack
- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Maps**: Google Maps JavaScript API
- **Styling**: Tailwind CSS
- **Status**: Available
- **UI**: Mobile-first responsive components

## Project Status
  **Under Development** - DEMO version for integrative project presentation
